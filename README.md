# PromptFinderPro

PromptFinderPro は、Windows に保存した AI 生成画像を、画像に埋め込まれたプロンプトやモデル名、LoRA 名で探すデスクトップアプリです。過去の生成設定を探し直す、同じプロンプトから作った候補を比較する、保存先が分かれた完全一致コピーを整理するといった作業に向いています。

## ダウンロード

**v1.1.2 · Windows 10 / 11（64 ビット）· ポータブル版 · Python 不要**

[Windows 版 ZIP](https://github.com/sakusaku0214/PromptFinder/releases/download/v1.1.2/PromptFinderPro_v1.1.2_Windows_x64.zip) · [SHA256SUMS.txt](https://github.com/sakusaku0214/PromptFinder/releases/download/v1.1.2/SHA256SUMS.txt) · [最新版のリリースページ](https://github.com/sakusaku0214/PromptFinder/releases/latest)

1. ZIP を右クリックし、「すべて展開」で書き込み可能なフォルダーに展開します。
2. 展開先の `PromptFinderPro.exe` を起動します。Windows の警告が表示された場合は、配布元と SHA-256 を確認してください。
3. 「フォルダ選択」で生成画像の保存先を指定し、「スキャン / 更新」を押します。

ZIP とチェックサムを同じフォルダーに保存し、PowerShell で以下を実行すると照合できます。`True` が表示されれば一致です。

```powershell
$actual = (Get-FileHash .\PromptFinderPro_v1.1.2_Windows_x64.zip -Algorithm SHA256).Hash
$expected = ((Get-Content .\SHA256SUMS.txt -TotalCount 1) -split '\s+')[0]
$actual -eq $expected
```

## 生成画像を探す

一般的な画像管理ソフトでは、撮影日、フォルダー、手動タグなどで写真や素材を整理できます。PromptFinderPro は、対応する生成メタデータから検索項目を作り、見つけた画像の生成設定をコピーして再利用する作業に特化しています。生成情報が削除された画像や未対応の形式では、埋め込み情報を使った検索はできません。

| 操作 | できること |
| --- | --- |
| スキャン / 更新 | 対象フォルダーを差分スキャンし、生成情報を SQLite の検索インデックスに登録します。「除外」でサブフォルダー名を指定でき、「強制再抽出」で登録済みの生成情報を読み直せます。 |
| 検索・絞り込み | プロンプトを全文検索し、モデル、LoRA、評価で絞り込めます。`blue_eyes -monochrome` のような除外検索や、ネガティブプロンプトを含める切り替えも使えます。 |
| 日本語キーワード | 日本語のタグ辞書や英訳を使って検索できます。自動翻訳時には検索語が Google の翻訳サービスに送信される場合があります。 |
| 類似プロンプト検索 | 選択した画像と、プロンプトの単語構成が近い画像を探します。 |
| 見た目類似検索（dHash） | 選択した画像と見た目の特徴が近い候補を探します。完全一致の確認には重複検索を使います。 |
| 詳細表示・再利用 | プレビュー、モデル、LoRA、評価、生成パラメータを確認できます。ポジティブ、ネガティブ、全生成パラメータのコピー、エクスプローラー表示、外部アプリへのドラッグ＆ドロップに対応します。 |
| 評価・整理 | 一覧上で `1`〜`5` で評価、`0` で評価解除、`Delete` で確認後に Windows のゴミ箱へ移動できます。 |

Stable Diffusion WebUI（AUTOMATIC1111 / Forge）の生成パラメータ、ComfyUI の埋め込みプロンプト、NovelAI のメタデータに対応しています。対応する生成情報を含む JPEG / WebP の Exif UserComment も読み取ります。取得できる項目は画像の保存方法や埋め込まれた内容によって異なります。

## 完全一致の重複を整理する

1. 「スキャン / 更新」で画像を登録し、「重複画像を検索（完全一致）」を押します。登録済み画像からファイルサイズで候補を絞り、SHA-256 で内容を照合します。再圧縮やメタデータ変更でファイル内容が異なる画像は一致しません。
2. 画面上部の進捗バーは、候補を調べている間はアニメーション表示、SHA-256 の照合中は処理済み枚数・候補枚数・進捗率を表示します。
3. 「古い重複を一括選択」で、各グループの更新日時が最も新しい1枚を残し、ほかのコピーを選択します。基準はファイルの最終更新日時です。
4. 選択対象を確認し、「選択した重複をゴミ箱へ」を押して確認ダイアログを承認します。重複検索画面では残す1枚が保護され、ゴミ箱へ移動する前に、対象と残す画像のファイル内容を再確認します。

画面上部の **検索結果** は現在の一覧に表示されている画像の枚数、**選択中** はそのうち選んでいる枚数です。通常検索、類似検索、重複検索で共通して使えます。重複検索の結果欄には重複の組数、整理候補枚数、読み取りに失敗した件数も表示されます。

## データの保存と更新

初回起動時に `ai_images_index_v2.db` と `config.json` が作られます。DB にはファイルパス、生成メタデータ、評価、検索インデックスが保存され、設定ファイルには対象フォルダーや表示設定が保存されます。スキャンと検索は画像ファイルを読み取ります。ゴミ箱へ移動するには明示的な操作と確認が必要です。

旧版から更新する場合は、アプリを終了して旧版フォルダーを保管し、新版は別の書き込み可能なフォルダーへ展開してください。既存の評価と設定を引き継ぐ場合は、旧版の DB と設定ファイルを新版の EXE があるフォルダーにコピーしてから起動します。配布 ZIP には EXE と案内文のみが入っています。

## ソースから起動する

Windows の Python 3.12 環境で、リポジトリのルートから実行します。

```powershell
python -m pip install PySide6 Pillow send2trash deep-translator pyinstaller
python prompt_finder_pro.py
```

EXE をビルドする場合は `python -m PyInstaller --clean PromptFinderPro.spec` を実行します。
