## Windowsユーザー向け：かんたん導入

**Python不要。Windows 10/11 64bit向けのポータブル版です。**

1. [Releases](https://github.com/sakusaku0214/PromptFinder/releases/latest) から `PromptFinderPro_v1.0.0_Windows_x64.zip` をダウンロード。
2. ZIPを右クリック → 「すべて展開」。ZIP内から直接起動しないでください。
3. 解凍した `PromptFinderPro.exe` を起動し、「フォルダ選択」→「スキャン / 更新」を実行。

- 初回起動時に `ai_images_index_v2.db` と `config.json` が作られます。個人用データなので公開・共有しないでください。
- Windows SmartScreenで警告が出る場合があります。配布元とSHA-256を確認し、不明なEXEを実行しないでください。
- Windowsの別フォルダーでEXEの起動とDB初期作成を確認しました。別PCでの完全動作は未確認です。
- 画像をゴミ箱へ移動する機能があります。重要な画像はバックアップしてください。

# AI生成画像プロンプト検索ツール (PromptFinderPro)

ローカルに保存された大量の AI 生成画像を非破壊でインデックス化し、**プロンプト検索（日本語翻訳・マイナス除外対応）・モデル/LoRA フィルタ・プロンプト類似検索・見た目類似検索（dHash）・高速選別**を快適に行える Windows 向けデスクトップアプリケーションです。

---

## 主な特徴

- **大量画像でも固まらない高速設計**
  - SQLite + FTS5 全文検索とインデックス最適化、検索処理のバックグラウンド実行により、数万〜十数万枚規模のライブラリでも UI がフリーズしにくい設計です。
  - サムネイルは非同期＆優先度制御（LIFO）で段階描画され、高速スクロール時も現在表示中の画像を優先して読み込みます。
- **幅広い生成ツール・メタデータに対応**
  - **Stable Diffusion WebUI (A1111 / Forge)**：ポジティブ／ネガティブ、モデル名、LoRA（タグ記述および `Lora hashes`）を抽出。
  - **ComfyUI**：サンプラー接続を辿ってポジティブ／ネガティブを分離抽出し、Checkpoint / UNet や各種 LoRA ノード（`rgthree` 等の動的キーを含む）にも対応。
  - **NovelAI**：`Description` / `Comment` (`uc`) / `Source` を解析。
  - **JPEG / WebP Exif UserComment**：AI 生成シグネチャを含むメタデータを判定・抽出し、通常の写真や非 AI 画像は自動除外。
- **直感的で柔軟な検索**
  - **強調構文・重み数値の自動正規化**：`(blue_eyes:1.2)` や `<lora:name:0.8>` などの記号・重みを除去して検索します。
  - **日本語タグ辞書＆自動翻訳**：日本語キーワードを英語タグへ変換して検索可能。
  - **マイナス検索（除外）**：`-monochrome` や `-黒髪` のように先頭に `-` を付けることで特定要素を除外できます。
  - **表記ゆれ・類義拡張 / ネガティブ検索**：アンダースコア表記ゆれや類義タグの展開、ネガティブプロンプトを含めた検索をワンクリックで切り替えられます。
- **2種類の類似検索**
  - **類似プロンプト検索**：選択中の画像とプロンプトの単語構成が近い画像を類似度（`%`）順に表示。
  - **見た目類似検索 (dHash)**：64bit 差分ハッシュ（ハミング距離）を用いて構図や配色が似た画像を抽出。
- **選別・コピー・外部連携を高速化**
  - サムネイル選択中に数字キー `1`〜`5` で 5 段階評価、`0` で評価解除、`Delete` キーで確認後に Windows のゴミ箱へ移動。
  - ポジティブ／ネガティブ／全パラメータのワンクリックコピー、エクスプローラー表示、ブラウザやエクスプローラーへの直接ドラッグ＆ドロップに対応。

## ダウンロードと起動方法

1. 配布ページから ZIP ファイル（例：`PromptFinderPro_v1.0.zip`）をダウンロードし、任意のフォルダに解凍します。
2. フォルダ内の **`PromptFinderPro.exe`** をダブルクリックして起動します。

> **初回起動時の警告について**  
> 個人ビルドの実行ファイルのため、初回起動時に Windows SmartScreen によって **「Windows によって PC が保護されました」** と表示される場合があります。その際は **「詳細情報」＞「実行」** をクリックして起動してください。

初回実行時、実行ファイルと同じフォルダに以下のファイルが自動生成されます。
- `ai_images_index_v2.db`：画像メタデータと検索インデックスを保存するデータベース
- `config.json`：対象フォルダ、除外設定、表示オプション、ウィンドウサイズの保存ファイル

---

## 基本的な使い方

1. **対象フォルダのスキャン**
   - **「フォルダ選択」** から画像が保存されているルートフォルダを指定します。
   - スキップしたいサブフォルダ名（例：`grids, extras, temp`）があれば **「除外」** 欄にカンマ区切りで入力します。
   - **「スキャン / 更新」** を押すと差分スキャンが実行されます。
   - 既存登録済み画像のモデル・LoRA・`dHash` を再抽出し直したい場合は、**「強制再抽出」** にチェックを入れてから **「スキャン / 更新」** を実行してください。
2. **検索と絞り込み**
   - 検索バーにキーワードを入力して `Enter`（または **「検索」**）を押します。
   - モデル、LoRA、評価、並び順の各ドロップダウンで条件を絞り込めます。
3. **詳細確認とアクション**
   - サムネイルをクリックすると右ペインにプレビュー、モデル／LoRA／評価バッジ、ポジティブプロンプト、ネガティブ／生成パラメータが表示されます。
   - 基準画像を1枚選んだ状態で **「類似プロンプト検索」** または **「見た目類似検索 (dHash)」** を押すと、似た画像をランキング表示できます。

## キーボードショートカット・操作一覧

| 操作 / キー | 機能 |
| :--- | :--- |
| `1` 〜 `5` | 選択中画像の評価を ★1 〜 ★5 に設定（一覧フォーカス時） |
| `0` | 選択中画像の評価を解除（一覧フォーカス時） |
| `Delete` | 選択中画像を Windows のゴミ箱へ移動（確認あり） |
| ドラッグ＆ドロップ | 選択画像を WebUI / ComfyUI ブラウザやエクスプローラーへ直接渡す |
| 右クリック | 類似検索、評価設定、各種コピー、場所を開く、ゴミ箱移動 |

## 自作ビルド（開発者向け）

Python 3.12 環境からソースコード（`prompt_finder_pro.py`）を実行・ビルドする場合は以下の手順で行います。

```bash
pip install PySide6 Pillow send2trash deep-translator pyinstaller
python prompt_finder_pro.py
```

単体実行ファイル（`.exe`）としてビルドする場合（任意で `app_icon.ico` を配置）：

```bash
pyinstaller --clean --noconsole --onefile --icon=app_icon.ico --add-data "app_icon.ico;." --name PromptFinderPro prompt_finder_pro.py
```
